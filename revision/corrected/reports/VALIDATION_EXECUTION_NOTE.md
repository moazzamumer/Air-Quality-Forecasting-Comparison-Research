# Corrected validation execution provenance

The first attempt to launch validation from the versioned supervisor used an inherited child-module command pointing to `revision.code.phase2_runner`. Its eight workers therefore executed the old, pre-correction implementation and wrote into the earlier validation artifact paths. No output from those workers was admitted into the corrected selection. The committed earlier validation files were restored from their Git checkpoint; the original artifact directory is clean. The discarded supervisor timings are preserved verbatim in [discarded_misrouted_validation_attempts.jsonl](../artifacts/phase2/discarded_misrouted_validation_attempts.jsonl).

The worker-module command was fixed to `revision.corrected.code.phase2_runner`. A corrected Prophet smoke fit confirmed output paths and the changed NO₂ scale. The full corrected validation then ran the remaining candidates, skipping that already completed smoke candidate. Its eight actual corrected supervisor events are in [supervisor.jsonl](../artifacts/phase2/supervisor.jsonl). The complete corrected candidate forecasts/metadata and [selection.json](../artifacts/phase2/selection.json) use the corrected protocol signature. One SARIMAX candidate did not converge and was excluded under the predefined rule.

Corrected validation timing summaries use only `supervisor.jsonl`. The discarded attempts remain visible for process accountability but do not enter model comparison, selection or corrected computational-cost totals. The saved raw dataset and submitted manuscript were not changed.
